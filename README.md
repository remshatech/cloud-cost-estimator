# Cloud Cost Estimator

A Python CLI tool to estimate AWS EC2 and S3 monthly costs.
Built as Project 0 of a 30-day hands-on cloud engineering program.

## What It Does

- Calculates EC2 monthly cost based on instance type and hours used
- Calculates S3 monthly storage cost
- Identifies what falls within the AWS free tier
- Generates a cost report saved to a text file

## Project Structure

```
cloud-cost-estimator/
├── main.py           # entry point — user input and output
├── calculator.py     # core logic — all cost calculations
├── requirements.txt  # no external dependencies
├── sample-output.txt # example report generated by the tool
└── README.md
```

## How to Run

Requires Python 3. No additional libraries needed.

```bash
git clone https://github.com/remshatech/cloud-cost-estimator
cd cloud-cost-estimator
python main.py
```

|---------|----------------|
